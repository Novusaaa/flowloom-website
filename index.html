常见问题

把重复工作组织成可执行的流程：接收请求、读取知识、分类判断，再生成回复或协作任务。你可以在画布上编辑步骤，测试运行，并查看每个节点的输入与输出。

可以。注册账号即可创建独立工作空间，或使用邀请加入团队。默认本地演示引擎无需 API Key；也可以由工作空间管理员配置真实模型。

管理员可以在后台配置 OpenAI 兼容接口地址、模型与 API Key。密钥由服务端加密保存，代理和工作流会使用工作空间配置的模型。模型服务费用与使用规则由接入的服务提供方决定。

每个工作空间使用独立数据库与加密密钥。站点后台只展示账号、系统状态和脱敏日志；提供包含完整性校验的快照与恢复工具。

支持 PDF、Word、Excel、Markdown 和纯文本。文档解析后可按内容检索，代理回答保留引用来源。对于大型知识库，需要结合实际文档数量与使用负载验收容量。

当前版本中的外部应用动作使用本地模拟器，生成可检查的执行产物，不会向第三方发送消息。接入真实连接器后，应按企业业务要求配置凭据、访问权限和操作确认。

支持单实例公开注册与私有化部署，提供独立工作空间、站点维护台、访问密钥与健康检查。正式上线前需在目标服务器完成 TLS、备份恢复与容量验收；当前版本不包含高可用集群。
