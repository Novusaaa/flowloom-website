## 本地开发

使用 Node.js 24 或更新版本。

```sh
npm ci
npm run dev
```

```sh
npm run build
```

构建输出位于 `docs/`。GitHub Pages 使用 `main` 分支的 `/docs` 目录。源代码更新后重新构建并提交 `docs/` 即可更新展示站。
